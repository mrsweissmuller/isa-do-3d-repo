# Art Tools

Cada um liga o que quiser em `Art Tools/Settings...`. Fica salvo em `UserSettings/IsaDo3DTools.asset`, fora do Git. A mesma janela abre as ferramentas e configura os programas de fora.

| Ferramenta                   | O que faz                                                                         |
| ---------------------------- | --------------------------------------------------------------------------------- |
| Object Editor                | Reposiciona pivô e encaixa objeto (janela, menu e botão na barra)                 |
| Material Batch               | Aplica um material em todos os selecionados (janela, menu e botão na barra)       |
| Hierarchy Organizer          | Grupos na Hierarchy e normalizar nomes (janela, menu e botão na barra)            |
| ↳ Color headers              | Cabeçalhos coloridos na Hierarchy e botão `≡` pra selecionar e fechar o grupo     |
| Scene View toolbar           | Atalhos na Scene View (só mostra os botões do que estiver ligado)                 |
| Create Material from Texture | Clique direito na textura `TEX_` cria o `MAT_` na pasta Materials ao lado         |
| Folder colors and badges     | Clique direito na pasta, Folder Color..., abre no mouse as cores, a cor livre e os selos. A cor vale pras pastas de dentro; fica em `UserSettings/IsaDo3DFolderColors.asset`, fora do Git |
| 3D software                  | Clique direito, Open in Blender (com Batex e Krita Bridge) e/ou Open in Maya      |
| Open texture in image editor | Clique direito, Open in Image Editor. Usa o programa de Preferences > External Tools > Image application, abre o fonte `.kra` quando é o Krita e recarrega ao salvar |
