# Isa do 3D Tools

| Define                        | Ferramenta                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------- |
| `ISADO3D_OBJECT_EDITOR`       | Object Editor (janela e botão na barra)                                         |
| `ISADO3D_MATERIAL_BATCH`      | Material Batch                                                                  |
| `ISADO3D_HIERARCHY_ORGANIZER` | Hierarchy Organizer (janela e botão na barra)                                   |
| `ISADO3D_HIERARCHY_HEADERS`   | ↳ cabeçalhos coloridos na Hierarchy e botão `≡` pra selecionar e fechar o grupo |
| `ISADO3D_LOD_BUILDER`         | LOD Group Builder                                                               |
| `ISADO3D_MISSING_SCRIPTS`     | Missing Scripts                                                                 |
| `ISADO3D_BLENDER`             | ⇄ Abrir no Blender, Batex e instalador do Krita Bridge                          |
| `ISADO3D_MAYA`                | ⇄ Abrir no Maya                                                                 |
| `ISADO3D_KRITA`               | Abrir no Krita e recarregar ao salvar                                           |
| `ISADO3D_OVERLAY`             | Barra na Scene View (só mostra os botões do que estiver ligado)                 |
